# Model Card: Primary Risk Model (generated)

Generated by `scripts/model_card.py` from the real backtest, sensitivity and survivorship results -- never hand-edited; re-run the script to refresh after any data or model change.

## Intended use

A research prototype that scores Indian listed companies for evidence-backed corporate-governance and financial-distress red flags. **Not investment advice, not a credit rating, and not validated for any production decision.** The real result below is that no model variant in this pipeline beats the training-fold base rate -- there is no demonstrated predictive skill to rely on.

## Data and outcomes

Verified-coverage universe (real companies with both a real IBBI Filing and a real CARE Filing): ['DHFL', 'FRETAIL', 'GENSOL', 'JETAIRWAYS', 'SPICEJET'] -- 5 companies. Window: [2017-08-17, 2026-07-21].

Pooled, coverage-restricted real counts: 36 company-month rows, 4 distinct positive companies, 5 distinct positive events.

**Statistically inconclusive: 5 distinct positive events is below the 30-event floor for any predictive-skill claim.** All results below are reported for completeness and methodology validation only, per the user's explicit condition (2026-10-31).

## Calibration

Isotonic regression only if the inner-validation calibration fold has >= 50 real positives; Platt scaling otherwise; uncalibrated with a stated reason if neither is possible. In the real walk-forward backtest, every fold's calibration fold had far fewer than 50 positives, so Platt scaling (or uncalibrated, where the inner split itself had too little data) was used throughout -- see `ledgerlight.modelling.models.calibrate` and its real per-fold reasons in `scripts/backtest.py`'s output.

**Deployment gap, disclosed**: the per-fold calibration map is not persisted with the final deployed artifact (`scripts/train_risk.py`); `scripts/score.py` reports `calibrated_probability == raw_probability` for that reason.

## Coverage limits

Only 5 companies in all of this project's universe have both real IBBI and real CARE coverage -- far smaller than the 15-company SEED-track set used elsewhere in this project. Most price-liquidity features are 55-100% missing in 2023-2025 within this universe (see `ledgerlight.modelling.data_quality_report`).

Survivorship: ALL 5 companies in this universe have a real confirmed trading-stop gap before the current price_bars coverage end -- the 'without later-delisted companies' comparison is empty. This restricted universe, by construction, consists only of companies that actually went through distress.

## Failure modes

- Inconclusive by construction: too few real distinct positive events (5 pooled) for any model to demonstrate real skill.
- The feature-shift leakage test shows a real, disclosed anomaly (shifted PR-AUC higher than unshifted) attributable to long same-episode label runs in this tiny dataset, not a demonstrated leak -- see `ledgerlight.modelling.leakage`.
- The univariate PR-AUC flag catches `days_since_last_downgrade` at 1.0 in the real data -- investigated (Phase 6 Correction 2 §1), confirmed NOT a temporal leak: every one of its 19 real non-null rows (9 positive, 10 negative) comes from a single company, FRETAIL (the other 4 have no qualifying downgrade ever recorded); the downgrade it cites for each row is a distinct, earlier, point-in-time-valid rating action, never the outcome event itself. The 'perfect' separation is a single-company autocorrelation artifact (FRETAIL's own rating agency went quiet for ~11 months before its real default), not a cross-company generalizable signal -- see `docs/modelling/data-quality.md` for the full real evidence trace.
- Deployment-time imputation and calibration are simplified relative to training time (see Calibration above) -- acceptable only because there is no real predictive signal at stake either way.

## Ethical considerations

- Not investment advice; must not be used for real trading, lending, or employment decisions.
- The verified-coverage universe is 5 specific, already-famous distress cases (DHFL, Future Retail, Gensol, Jet Airways, SpiceJet) -- any score here reflects hindsight-selected companies, not a general-purpose early-warning signal.
- SpiceJet's inclusion as a real positive/negative case needs human review: it was originally a Phase 0 'no known distress' control company, but a real search later found 8 distinct NCLT insolvency petitions against it (2021-2026) -- flagged in `docs/phase-3/progress.md`, not resolved unilaterally.
