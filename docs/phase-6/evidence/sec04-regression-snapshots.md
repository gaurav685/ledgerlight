golden file.

## How to update

Never hand-edit `tests/fixtures/regression_snapshots.json`. Run:

```
python3 -m uv run python scripts/update_regression_snapshots.py --confirm --reason "<why>"
```

then add a new dated bullet above explaining what changed and why, then
re-run `make test-regression` to confirm the new file is self-consistent.
