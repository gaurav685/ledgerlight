`tests/fixtures/regression_snapshots.json` freezes real values from this
project's own already-persisted production database (not synthetic, not
generated by this phase's own test or demo runs). This file records which
real subject was chosen for each category and why, and must be updated
every time `scripts/update_regression_snapshots.py --confirm` changes the
golden file.

## How to update

Never hand-edit `tests/fixtures/regression_snapshots.json`. Run:

```
python3 -m uv run python scripts/update_regression_snapshots.py --confirm --reason "<why>"
```

then add a new dated bullet above explaining what changed and why, then
re-run `make test-regression` to confirm the new file is self-consistent.
